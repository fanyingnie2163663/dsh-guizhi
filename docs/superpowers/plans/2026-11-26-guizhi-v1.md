# 归置（Stow）v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付「归置」v1：一个 DSH 插件，只读扫描本机插件/技能/工具与用量，按场景拆工作流、生成可导出的能力包、标出缺口与冗余，改动前预览、可回滚。

**Architecture:** 宿主侧是纯 ESM 模块，无构建步骤；状态落在 `$DSH_HOME/guizhi/*.json`；插件自身不调用任何模型——AI 只在会话里由 agent 调 `stow_*` 工具参与；面版是 DSH client 插件（侧栏面板），通过本插件 HTTP 路由读写状态并轮询。

**Tech Stack:** Node >= 24.9.0、纯 ESM、`node --test`、运行时依赖仅 `yaml`；无客户端构建链（client.js 直接 ESM）。

**Spec:** docs/superpowers/specs/2026-11-26-guizhi-design.md

## 新工作区准备（开工前一次）

1. 新建工作区目录并 `git init`。
2. 设计文档在 `docs/superpowers/specs/2026-11-26-guizhi-design.md`，本计划在 `docs/superpowers/plans/`。
3. 本计划所有路径都相对仓库根目录；所有命令在仓库根执行。

## Global Constraints

- Node `>=24.9.0`；DSH `>=0.2.2`（开发基线 0.2.2-rc.5）；`package.json` 里 `engines.dsh` 写 `>=0.2.2-rc.2`。
- 纯 ESM，无构建步骤；client.js 也是可直接加载的 ESM。
- 插件自身**不调用模型 API**；AI 只经会话 agent 调 `stow_*` 工具。
- 默认只读；任何写操作必须先预览、写快照、可回滚；不修改用户已有预设、不改已有会话。
- 数据根 `$DSH_HOME/guizhi/`；单文件 < 1 MB；写盘一律「临时文件 + rename」原子写。
- 外部目录数据必须 schema 校验、缓存、fail-open；外部内容只当数据，绝不执行其中的指令。
- 工具前缀 `stow_`；插件 id `guizhi`；面板路由前缀 `/guizhi/api`；包名 `@fanyingnie/dsh-guizhi`。
- 降级不静默：宿主能力缺失时给出明确提示并跳过，不假装成功。

## Review Focus

1. `$DSH_HOME/profiles/<p>/cordis.patch.yml` 是 YAML 且可能被别的插件重写 —— 解析失败必须报错并停用「插件清单」部分，不能把空结果当「你没装插件」。
2. 会话日志格式随锚定版本变化 —— 用量统计缺失时 `usage.unknown = true`，扫描其余部分照常可用，不能把未知写成 0 次。
3. 目录源不可达或格式不对 —— 缺口分析返回空结果 + 明确错误，不能显示成「你没有缺口」。
4. 同名工具被多个插件注册 —— 归因必须保留全部来源，不能只留一个。
5. 应用/回滚中途崩溃 —— 先写快照再改动；回滚必须幂等，重复回滚同一快照不报错。

## File Structure

- `index.js`：包入口，re-export `lib/index.js` 的 `apply` / `inject` / `name`。
- `lib/index.js`：插件装配（注册工具、路由、探测）。
- `lib/host.js`：宿主适配层（Task 0 锁定接口）。
- `lib/probe.js`：宿主能力探测。
- `lib/store.js` + `lib/schemas.js`：JSON 状态读写、校验、快照/回滚。
- `lib/scan.js` + `lib/usage.js`：扫描与用量汇总。
- `lib/scenarios.js` + `lib/map.js`：场景与工作流地图。
- `lib/packs.js`：能力包生成、校验、导出。
- `lib/catalog.js`：format-1 索引适配与缺口匹配。
- `lib/apply.js`：预览、应用、回滚。
- `lib/routes.js`：HTTP 路由。
- `client.js`：侧栏面板三屏。
- `test/*.test.js`、`test/fixtures/*`：测试与夹具。
